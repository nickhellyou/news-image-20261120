The World in One Day — a front page summing up Friday 20 November 2026: 40 numbered stories across 7 regions, a dotted world map with numbered pins, a day-in-numbers strip, and a DATE CHECK box that keeps Thursday's stories off the page. Lead stories: Cyclone Akvan comes ashore in India, COP31 reaches its final day, Anthropic soars on its Nasdaq debut, the three leaders issue a peace declaration in Shenzhen, Europe readies talks with Russia, the Senate rejects the Iran war-powers bid, and Arizona opens a criminal probe into OpenAI. Every story was cross-checked against wire and broadsheet reports published that day; disputed claims are attributed, not stated as fact. The image is drawn programmatically (PIL) so every word renders crisply — no AI-generated text.

## Run it

```sh
python3 main.py
```

Writes the baked front page to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Deterministic: both runs write the same bytes.
